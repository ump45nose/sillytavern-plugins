# YYB 微信取码共用能力

## 范围与关键决定

- 本任务只维护 `common/wechat_code.cjs`、专用测试、本计划和 `docs/YYB_LOGIN.md`；不修改平台业务、运行器、全局来源清单或生产调度。
- 接口固定为 `getCode({url, token, account}, appid) -> Promise<string>`。调用方负责读取私有配置；客户端只提交一个目标账号/AppID 的取码请求，不缓存 code 或商家会话。
- 当前依据为 YYB-Go-Enhanced v0.2.33，提交 `fe1cf72495498a6a7c0ddcce4c80d93fc163788a`；上游参考检出在仓库外 `/tmp/benefits-yyb-reference-20261019`，没有复制上游实现。
- 标准接口 `POST /wxapp/getCode`，Bearer 协议令牌，JSON `{ref: account, app_id: appid}`。实际响应为外层 `code:0`，内层 `data.result: {code: string, errMsg: "login:ok"}`；不从旧版/其他服务响应中猜取凭据。
- 使用 Node 内置 HTTP/HTTPS，完整调用限时 30 秒、响应上限 64 KiB、TLS 验证、不跟随重定向、不重试取码；错误仅给稳定脱敏原因。
- 同账号取码串行由已固定版本的 YYB 服务实现，客户端不引入另一个跨平台状态库或锁服务。
- NAS 无现成 YYB 容器。部署方案归正式 automation 组，复用现有网络与 SQLite，保留镜像原生身份；本轮不变更正式 Compose、不启动常驻服务。

## 验收标准

- localhost 协议测试证明 endpoint、请求字段、Bearer 认证、成功 envelope 解析与只返回 code。
- 明确拒绝未配置凭据、重定向、认证拒绝、账号冲突、非成功业务码/errMsg、缺失 code、超限响应及连接中断；错误不含 URL、token、账号或响应正文。
- 实测完整调用 deadline，不让持续慢响应绕过限时；请求失败后不自动重发。
- 固定镜像与来源对应，部署片段通过 Compose 校验；如可行，以临时隔离容器验证启动、健康和协议鉴权，不操作真实微信账号。
- 真实扫码、影视飓风与 Olé 各自取码、商家登录和续期分项记录，不用服务健康或其他 AppID 成功代替。
