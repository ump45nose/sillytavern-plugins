# 0.3 staged acceptance

Open MoviePilot and select **主题曲管理** in the Organize sidebar. The hash-router URL is `/#/plugin-app/ThemeStudio/main`.

The initial release deliberately keeps `automation_enabled` and `migration_enabled` false. This is an audition gate, not a requirement to approve every future item.

1. Use an eight-title tuning set and a separate four-title validation set. Include movies, Chinese series and anime. Keep the chosen identities in private state, not the public repository.
2. Search and inspect the top three candidates. “正确” records work/track correctness; “更喜欢这个版本” records preference; “错误” excludes that source from subsequent automatic adoption for the item.
3. Click “试听” on a result card. The card shows preparation status and then its own full-track audio player; full previews are reused, and starting another result pauses the previous one. Click “应用完整曲目” on that same card to keep the entire track. Only click “裁剪（可选）” if you want start/end fields, then generate and audition a cropped version before applying it. Opening the controls alone does not trim anything; “恢复完整曲目” returns to the original full prepared track. Uploads and links also default to full length and have optional cropping. Legacy 45-second previews are rebuilt from their retained original source, not reused as complete tracks. Automatic downloads and fallback upgrades keep full online tracks; local video extraction remains a selected interval.
4. Apply only after the preview is satisfactory. Successful manual application marks the item complete and locks it. Existing unrelated audio requires explicit takeover. A failed replacement registration restores the old hash-matched file.
5. Require at least ten approved top-three results out of twelve, no wrong-work automatic adoption, and one successful real application before enabling automatic 25-item batches.

Execution completion, source quality and user completion are separate fields. Container health, candidate counts and file existence are not quality acceptance.

The socket API has no public listener. MoviePilot authenticates the proxy using its own permissions; the Worker alone owns SQLite. `/session` refreshes the host resource cookie only for an already authenticated host identity.

Supported public platform references are persisted so new candidate handles remain playable after a Worker restart without repeating the entire search. Direct/signed download URLs are not retained; older candidates without a reference are re-resolved using their source hashes and may require a new search. Queued tasks survive restarts. An interrupted application is not replayed blindly: replacement journals recover an unchanged old backup, while an interrupted first write is retained for manual review.

“检索名称与已执行的查询词” shows the local title, original title, available aliases and recorded queries. Each search provider receives at most four queries and ten results per query. The original title is not necessarily English; an additional English title is used only when supplied by the media metadata as an alias. MusicBrainz does not promote an arbitrary first album track into a theme query, and undated same-name albums are rejected when the film year is known.

Movie searches use source-specific query profiles calibrated with Gladiator: at most three measured templates, with an explicit keyword/identified theme track taking precedence within the four-query ceiling. The benchmark ranks top-three work precision, clean versions and likely-original recordings, then adds unique results and both title languages when they performed well. Its title/album labels are not listening approval. Bilibili currently has only one qualified measured template; blocked requests are not judged as bad queries. Series/anime opening queries are unchanged. Optional absent cookie files use anonymous access; platform cookies are isolated.

Current limitations: original-source waveform preview is bounded to ten minutes; source availability and download authorization vary. MusicBrainz is metadata-only. WhatSong and Tunefind remain disabled pending API access. User preference is retained as evidence, not treated as proof of correct identity. The CPU music classifier does not identify a film's actual theme by listening alone.
