# AI 资源中心 RP 联动

独立工作区从聚合仓库 ac4281512c0a994f00d0482f5d83abae37ffd42c 创建，只改 SillyTavern Workbench 的资源中心集成及其构建产物。没有合并用户主工作树或推送远端。

中心在 fn 的 18321 保存连接。酒馆插件读取限定 RP 范围的凭据，原生保存成功后提交明确的连接字段及版本；中心修改由用户应用到原生连接。未保存草稿、角色卡、世界书、提示词和采样预设不上传。

共用 ResourceCenterLink 的 Workbench 面板和独立薄扩展。生产实例没有安装整个 Workbench，故只部署 extension-resource-center 到生产 extensions/ai-resource-center。中心地址、凭据、绑定、待交队列、回执与错误存在原生 extensionSettings.aiResourceCenter，不另造配置存储。

保存事件有不可变事件标识。离线保留，确认后移除；并发的后续保存不会覆盖待交事件。409 保留原生保存内容并显示双方差异。应用连接通过原生 secrets API 保存所需凭据，但不触发 SECRET_WRITTEN 自动连接；保持未知原生配置字段，明确更新下一次请求的 API、模型和代理设置，不探测上游。

手动暂停的绑定从下一次生成拦截，不中断当前生成。中心配置读取、导入、排序、编辑和应用均不调用 RP 上游。用户在扩展设置中自行选择原生连接对应的中心连接；不批量绑定生产连接。

验证：类型检查、构建和 46 项测试通过。隔离原生酒馆实例完成保存、fn 回执、暂停拦截、实际下一请求配置、未知字段保留；应用过程上游请求数为 0。独立扩展已复制到生产目录，生产连接未自动替换。验收实例、虚拟站点和限定验收凭据已清理。

回退时移除自有 ai-resource-center 扩展目录并恢复此提交前的 Workbench 构建即可；保留用户原生连接和 secrets。执行前若仍有待交保存，先处理或导出其内容。独立中心停机不影响已有酒馆直连。
