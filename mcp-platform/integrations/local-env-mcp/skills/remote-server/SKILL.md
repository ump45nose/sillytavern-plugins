---
name: remote-server
description: 需要读写远程服务器文件、修改代码或配置、执行命令、查看日志和管理进程时使用。
---

先调用 `list_devices` 核对目标远程服务器及在线状态，再选用对应设备前缀的工具。执行前确认服务器、路径和用户身份；文件修改前先读取相关内容。

终端启动最多等待10秒；长任务保留返回的PID和 `executor_generation`。后续读取输出、发送输入、终止进程或管理搜索时，携带创建时的同一代次。

客户端或网关断线后，执行器仍在线时可继续查询原会话。`session_invalid` 表示需新建会话；`device_offline` 表示调用未发送；`outcome_unknown` 表示可能已经执行，应先核对实际状态，不自动重试命令或写入。

一台远程服务器离线时，其他在线服务器仍可使用。不同接入通路的进程会话独立，不能混用PID。
