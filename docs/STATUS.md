## 边界

本项目负责六个平台的确定性业务操作和结构化结果。Hermes cron、日报与 Telegram 属于外部调用方，不列为脚本仓库必须实现的能力。没有容器部署要求或新常驻服务。

平台入口各自声明 Task，公共 runner 无平台名分支。CookieCloud 是按需公共凭据读取器，浏览器/模型依赖延迟加载；HTTP 平台不安装或启动浏览器。
