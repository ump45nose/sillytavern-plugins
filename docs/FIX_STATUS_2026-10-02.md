# 2026-10-02 架构审查后的修复

本轮针对最新草稿版本的已复现问题修复；保留单仓库、原生一次性任务和平台目录。没有通过容器、常驻服务或更大的编排框架替代问题，也没有执行真实账号操作或部署到 NAS。

## 执行与业务边界

- 通用运行器移除整个平台注册签到缓存短路。平台负责具体动作的当前状态、意图记录与只读核验
- 适配器异常退出、超时、中断、清理或落盘失败时，保留同一 run 且通过协议验证的已确认业务结果
- 即使运行目录不可用，仍尽力在 stdout 提供结构化失败结果
- Rewards full 每个阶段完成后发布标准部分结果；未运行能力保持 unknown，后续失败不覆盖先前成果
- 审批范围同时绑定 request_id、origin_run_id、phase、账号、能力、目标及当前证据指纹

## 浏览器回收

原生 Linux 启动器采用进程本地 subreaper、父子归属验证与 pidfd 回收分离后代。实际探测内核能力后才启动适配器。使用真实锁定版本的 Firefox/Patchright launcher 加本地 fake-browser，覆盖适配器冻结和强杀；不是实际网站业务验收。

launcher 自身被 SIGKILL 时不能承诺立即收回全部孤儿。清理标记会阻止后续浏览器任务重叠；同次主机启动内不凭 PID 消失或记录年龄自动解除。详见 [运行恢复说明](RUNTIME_RECOVERY.md)。没有修改系统服务、网络或安全设置。

## 平台修复

### Rewards

- 内置 7,000 条搜索词先生成有界执行队列；自定义队列仍有输入上限
- Punchcard 原生绑定保留分类器需要的类型、进度、属性和目标地址，搜索型任务和手动领取开关不会因字段丢失失效
- 快照与业务预检共用限制判定，风险提示不再等到搜索阶段才检查
- Action ID 和请求数据在提交意图前校验；同一数据块内冲突 ID 拒绝使用。Goal 先检查对话框、手动选择与 Next 控件，实际点击前才写提交意图
- 未来活动不执行，extra 的已完成结果在后续批准要求或错误中保留
- APP 每日/阅读状态使用一个按业务日有界轮转的文件，导入当前日的旧尝试状态；不会把不确定的多日促销记录随便清空
- 按明确 enabled 能力选择依赖，APP-only 绑定不再要求 desktop state、parser 或浏览器快照。可信调用方必须显式提供 enabled

### HTTP 平台

- 阿里云逐一记录 15 个社区（含空 code 的“我的社区”）的事实，不能因前一个社区完成就把后一个异常汇总成完成；不信任旧的聚合确认来跳过全部社区
- SMZDM 已签到仍进入奖励查询，签到与额外领取分别记录意图；按账号及业务日独立迁移旧签到和额外奖励回执，避免旧奖励被重复领取。没有领取回执的模糊结果保持 unknown，不盲目重发
- V2EX 在实际 requests 传输边界限制解码后响应至 1 MiB，保留 TLS 验证与受控跳转；保留待确认兑换，优先通过余额记录确认，避免重复领取
- 状态文件只保存账号代号、业务日和动作事实，不保存 Cookie、请求正文或平台原始响应

### Epic / Laowang

- Epic 使用有界可见图像摘要及会话/容器身份区分同 iframe 内刷新的挑战
- 结算观察包括可见、合法来源的 frame，并要求实际业务就绪证据；门禁处理使用当前观测容器
- 下单后先用独立只读页面核验归属，再决定是否仍需处理挑战，避免被已无关的遮罩拦住。真实 Playwright 只读超时归一化后有限重试；其他确定错误及授权错误仍向上传递
- Laowang 只有成功 HTTP 状态的精确 _ok 视为已通过。503、HTML、缺失/不明反馈保持 unknown，不触发刷新重试
- 同次调用的批准等待有界，取消/超时不继续动作；新增原始站点顺序的 base → qiandao → challenge 用例

## 仍未接通的真实能力

修复组件不等于已完成部署。Epic 公共领取入口仍有闸门；其具体购物车/商品证据、部分认证和交互分支仍需接线。Laowang 普通跨进程暂停会丢失动作响应页，未取得站点可安全读回的 continuation 前，不能靠删意图或重发 qiandao 假装恢复。

已检索 Hermes 官方插件和审批源码。一般 approved=true 可能来自允许列表或无人值守设置，不能当作这次本人确认；通用消息命令也不天然提供精确请求及响应者证明。实际 Hermes 版本、私聊/群聊/其他交互入口尚待确认。该接线不采用伪造批准文件、自动通过标志或假通知回调，也不将 TTY 方案冒充用户的无人值守 NAS 目标。

同一生命周期的多日促销未知提交仍可能需要人工核验。通用历史目录保留策略、真实页面兼容性、NAS 内核/架构和峰值内存也尚未验收。先前空启动器约 13 MiB 的测量不能代表实际浏览器任务的内存预算。
