## 已实施

- 每个来源有异常边界；未知 bundle 异常留在失败队列并继续后续来源。缺少 mimetype 的 EPUB 转为 `epub_invalid`。认证、验证码、限流和账号变化由 `AccountGuard` 控制，阻止本轮同账号继续请求；小红书保留持久化熔断。
- 公共 `media.valid_media` 仅读取 16 字节文件头，Pixiv 不再为校验媒体导入 EH/XHS 模块。
- 小红书在已见页中仍返回未完成的任务，以更新访问令牌；URL 变化时使旧详情缓存失效，保留命名与 first_seen。已完成任务不重复下载。页数/条目预算耗尽显示 `partial` 和结束原因。
- 来源名称、平台、适配器、基线/日期策略及显示名统一登记在 `sources.py`。适配器按需创建；片单入库调度归片单适配器；bili-sync 凭据读取归独立只读 provider。
- 独立调度器锁只限制常驻实例；worker 锁仅包围实际同步或登录，Cookie 同步有单独锁。重启按持久化的最近周期完成时间继续 8 小时调度。
- 数据库连接与版本化迁移分离。写入服务启动显式迁移到 schema 1；普通连接不迁移，`status` 使用 SQLite 只读模式。片单 API 不校验下载平台配置。
- 修复手动片单日期解析缺少 import，以及简介以“上映日期：”结束时的国家解析异常。现有工作区中已部署的手动片单功能一并纳入源码提交，使镜像可从 Git 重建。
- 旧大 Markdown 与 Telegram relayout 移入独立维护模块；失效的 x-review 命令下线，历史状态保留。模板移除旧 markdown_scope，维护模块仍能读取历史配置。
- 日报补充受限扫描原因和 Wallabag 图片不完整数量。仅做本地报告预览，没有额外发送消息或修改 Hermes Cron。
