模块库

每个采集来源对应一个模块，统一结构：图标 + 标题 + 来源 + 更新时间，正文分「简略」与「详细」两种形态。简略版固定高度 192，用于主页拼贴；详细版按内容伸展，并能根据所在宽度自适应。页面只负责把模块排进 12 列栅格。

菜单栏与快捷浮窗

菜单栏图标是最高频的入口：显示今天到期的任务数和下一个日程，有需要处理的事时出现陶土色圆点。两个全局快捷键在任何应用里呼出浮窗，输入完回车即回到原来的工作。
