字号与角色

Anthropic 的风格要点：标题和大数字用衬线、字重偏轻（400 而不是 600）、大字号收紧字距；界面文字用无衬线、正文行距宽松；强调靠字重 550 和颜色深浅，而不是加粗到 700。中文跟随同一套：衬线位置用 Anthropic Serif Text 汉字（缺的标点落到宋体），无衬线位置用苹方。
