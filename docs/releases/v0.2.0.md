# v0.2.0：独立人物与交互 CRM

一个服务进程，保留人物资料、可编辑的多人交互、附件、微信私聊增量归档，以及 HTTP / MCP 的 14 个读写工具。

- 连续私聊默认按 30 分钟间隔聚合；跨日、跨同步批次不断开。
- 重复消息跳过、新消息追加，不覆盖用户或 AI 编辑过的正文。
- 支持搜索、游标分页、人物合并、来源身份绑定和分块附件读写。
- 不依赖 Personal Data Hub，不包含日报、事件推送、Google/Memos、Fact、提醒、画像或评分。

## 安装和启动

```bash
git clone https://github.com/ump45nose/personal-crm.git
cd personal-crm
uv sync --locked
cp .env.example .env
# 设置 CRM_API_TOKEN；公网 MCP 按 docs/deployment.md 配置 OAuth。
uv run personal-crm migrate
uv run personal-crm-server
```

HTTP：`/api/v1/crm`；MCP：`/mcp`。默认 SQLite，也支持既有 PostgreSQL。

认证沿用固定提交的私有 `mcp-platform` 库；安装环境需要该 Git 仓库的读取权限。HTTP 配置使用 `CRM_API_TOKEN` / `CRM_VIEWER_TOKEN`，不读取 Hub 配置。微信采集沿用原读取器、身份、checkpoint 和媒体队列。

新库只创建当前 `crm_*` 表；旧数据库可保留既有表并执行一次性转换。已经处于 `004_person_archive` 的数据库可以直接使用。请先备份再迁移；本次仓库发布没有替换线上宿主服务。
