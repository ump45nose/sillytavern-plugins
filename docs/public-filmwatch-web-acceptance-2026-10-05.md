## 验收中修正

FilmWatchlist 公网预检此前先按分辨率排序，而最终选择先按质量档位排序。在超过八个 2160p WEB 候选时，更高质量档的 1080p BluRay 可能落在预检批次外，随后被保守核验规则阻止提交。现使预检顺序与最终选择的质量档位一致，保留视频体积核验与暂停规则。
