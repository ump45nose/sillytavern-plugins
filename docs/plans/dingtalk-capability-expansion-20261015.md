# 钉钉 MCP 能力补齐

## 范围与决定

- 用户明确要求覆盖 dws 已支持的全部钉钉业务场景，不限于现有用途；含个人聊天、群聊、历史与搜索、文件、白板、人事、合同及开发平台能力。
- 继续使用现有 MCPHub 和官方远程 MCP，不引入 dws 转接服务；保留原十一个上游、北向 OAuth、App 身份及持久卷。
- 对照 dws 完整 Schema、官方静态和补充服务登记、显式直连端点及市场详情核对覆盖；本机 v1.0.62 的完整 Schema 为 31 个产品、1435 个 CLI 命令，其中许多是同一底层工具的组合或本地处理，不将命令数当作 MCP 工具数。
- 按实际工具清单判断覆盖和重复；仅为缺失能力新增接入。已有 AI 表格发现 4 个目录工具未出现在当前缓存，将定向刷新核对。官方目录中不存在、未开放或当前账号无权使用的能力明确记录。
- 非秘密接入配置与中文说明保存在业务项目；令牌、客户端密钥和授权状态只在现有私有运行数据中维护。
- 配置新增工具不代表执行业务写入；本次业务验证仅做只读查询。需用户登录时提供当前有效的授权入口。
- 在现有独立工作区修改源码，通过 MCPHub 原生 API 和既有部署锁应用配置；不覆盖主工作树其他修改。

## 验收

- 官方来源、已有覆盖、新增能力和未开放能力可核对。
- 新服务在现有 MCP 入口可发现，聊天优先完成只读业务验证；需要用户授权的服务给出明确待办。
- 原十一个服务与北向身份保留，入口健康、OAuth 发现和匿名拒绝正常。
- 非秘密源配置与实际接入匹配，中文说明和进度同步；执行适量验证、源码差异检查及启动检查。
