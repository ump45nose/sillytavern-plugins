# Epic 与 Rewards 异常修复

## 范围与决定

- Epic：以明确名称的唯一可见商品按钮统一识别商品页就绪、所有权、领取路径与领取入口；沿用商品身份、零价、订单 intent 与不重放保护。
- Epic 后续实测：新版页面同时有直接领取和购物车图标，优先直接领取；复用刚打开的同一商品，独立所有权回查仍使用新页面。第三方验证码 SDK 导入前禁止包目录日志写入，失败或超时只处理一次，异常日志仅保留类型与代码位置。
- 网络实测：部分新版静态资源返回 403 HTML，Firefox 将其报告为 `NS_ERROR_CORRUPTED_CONTENT`；编码假设已排除，不保留新增编码绕行。403 直接报告，不能把静态按钮当成功加载的页面。
- nas-cron-jobs 仅补充上述实际故障的中文通知标签，不改变调度与投递。
- Rewards：最终快照确认同一周卡的开放任务完成后，更新该能力及其明细；保留原始阶段错误在事件日志中。跨周、最终快照失败和未确认积分不能按成功处理。
