# 第二阶段验证记录

Mac 原生客户端在 `apps/mac-client`，与采集 Agent 和 NAS 公共基座使用同一仓库管理。参考本机 Token Monitor 0.67.0 的菜单栏常驻、单实例、独立窗口及开机启动交互；客户端使用 SwiftUI / AppKit，不引入另一个采集实现。

服务增加只读凭据、来源类型枚举和轻量分页浏览。`hub_record_previews` 保存确定性提取的短字段，归档 JSON、修订、附件和原身份不变。现有归档可运行 `hub backfill-previews` 一次性补齐。清理记录时同步删除查看字段，既有墓碑规则继续生效。

冒烟脚本：`.venv/bin/python checks/stage2-smoke.py`，覆盖官方账单重复推送、只读凭据无法写入、列表不携带原始大对象、分页、字面量搜索、时间筛选、详情和附件。使用临时存储，不写生产测试信息。

真机安装、运行验证结果在完成后记录。
